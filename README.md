# Symaira Scoop Bucket

![Symaira Scoop Bucket](docs/assets/social-preview.png)

Scoop bucket for Symaira tools.

## Usage

```powershell
scoop bucket add symaira https://github.com/danieljustus/scoop-bucket
scoop install symaira/symvault
```

The `symvault` manifest is kept at the repository root so Scoop discovers it when listing the bucket.
